# Evals_estudiantes

Bienvenidos al repositorio **Evals_estudiantes** 👋

Este espacio ha sido creado para que los alumnos puedan **subir, compartir y consultar los proyectos desarrollados durante las clases**, así como las modificaciones, mejoras y experimentos que realicen de manera personal.

## 🎯 Objetivo

El propósito de este repositorio es crear un espacio colaborativo donde podamos:

- 📚 Compartir los proyectos realizados durante el curso.
- 💡 Mostrar modificaciones y mejoras personales.
- 🧪 Experimentar con nuevas ideas y enfoques.
- 🤝 Compartir soluciones y buenas prácticas.
- 🔎 Consultar el trabajo realizado por otros compañeros.
- 🚀 Fomentar la creatividad y el aprendizaje colaborativo.

## 📂 Organización

Cada alumno puede crear una carpeta para sus proyectos dentro del repositorio.

Se recomienda utilizar una estructura como:

```text
Evals_estudiantes/
│
├── Proyecto01/
│   ├── README.md
│   ├── codigo/
│   └── recursos/
│
├── Proyecto02/
│   ├── README.md
│   ├── codigo/
│   └── recursos/
│
└── ...
```

También pueden organizar los proyectos de acuerdo con la estructura que consideren más conveniente.

## ✨ Proyectos y modificaciones personales

Los proyectos vistos durante las clases pueden utilizarse como punto de partida para desarrollar nuevas ideas.

Por ejemplo:

- Agregar nuevas funcionalidades.
- Probar diferentes modelos de IA.
- Mejorar prompts.
- Incorporar nuevas herramientas.
- Cambiar la interfaz.
- Optimizar el código.
- Experimentar con diferentes técnicas de evaluación.
- Crear una aplicación completamente nueva a partir de lo aprendido.

La idea es que el repositorio no sea únicamente un lugar para entregar tareas, sino un espacio para **experimentar y compartir conocimiento**.

## 🤝 Comparte tus ideas

Si realizaste una modificación interesante o encontraste una forma diferente de resolver un problema, **compártela con los demás**.

No es necesario que el proyecto sea perfecto. El objetivo es aprender de los experimentos, errores y soluciones de todos.

> 💡 Una buena idea puede servir como punto de partida para que alguien más construya algo todavía mejor.

## 📌 Recomendaciones

Al subir un proyecto, procura incluir un `README.md` dentro de su carpeta explicando brevemente:

- ¿Qué hace el proyecto?
- ¿Qué tecnologías o herramientas utiliza?
- ¿Cómo se puede ejecutar?
- ¿Qué modificaciones realizaste?
- ¿Qué aprendiste?
- ¿Qué mejoras futuras propondrías?

## 🌟 Participación

Este repositorio es un espacio colaborativo. **Siéntete libre de experimentar, modificar, proponer y compartir.**

La intención es que, entre todos, podamos construir una colección de proyectos e ideas que sirva como referencia para continuar aprendiendo sobre **IA, Evals y sistemas de IA**.
